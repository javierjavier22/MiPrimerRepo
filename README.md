# O.FRE.SER — Mockup de rediseño web

Prototipo navegable para definir la nueva experiencia web de O.FRE.SER antes de que Blackfish implemente la versión productiva en Odoo.

## Objetivos

- Priorizar **Minería** como vertical insignia.
- Dar una experiencia B2B sólida para **Industrias y Empresas**.
- Mantener una entrada clara para **Hogares y Comercios** y búsquedas locales como “fumigación Salta”.
- Incorporar un **Centro de Conocimiento** para construir autoridad temática y contenidos orgánicos sobre roedores, cucarachas, mosquitos, alacranes, etc.
- Dar protagonismo a la certificación **IRAM-ISO 9001:2015 (RI 9000-8842)** y **IRAM-ISO 14001:2015 (RI 14000-1012)**.
- Reservar espacios para las nuevas fotos y videos profesionales sin cargarlos todavía.

## Importante sobre SEO

Este prototipo tiene `noindex,nofollow` deliberadamente para no competir con `ofreser.com.ar`. La versión productiva NO debe copiar la navegación hash del mockup. Blackfish deberá implementar páginas y URLs reales e indexables, por ejemplo:

- `/control-de-plagas-mineria`
- `/control-de-plagas-salta`
- `/manejo-integrado-de-plagas`
- `/plagas/roedores`
- `/plagas/cucarachas`
- `/industrias/alimenticia`

El rediseño productivo también deberá contemplar inventario de URLs actuales, redirecciones 301, titles, descriptions, canonical, sitemap XML, robots, schema pertinente, enlaces internos, Core Web Vitals, imágenes WebP/AVIF y contenido HTML semántico.

## Estado

V1 conceptual. Incluye Home, Minería, Industria, Hogares/Comercios, Centro de Conocimiento, ficha de Roedores y Certificaciones. Las fotos, videos, logos finales y el copy técnico/científico definitivo se incorporarán en iteraciones posteriores.
